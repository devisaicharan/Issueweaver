IssueWeaver 1.7.0 - Google sign-in / Netlify + Supabase

1. Extract this ZIP into a NEW folder on Windows. Do not replace your local IssueWeaver folder.
2. Double-click DEPLOY-NETLIFY.bat.
3. Approve the normal Netlify login in your browser.
4. Choose to create a NEW site when prompted. Do not select CampusOS.
5. After deployment, copy the production https://....netlify.app URL and send it in our chat.

This source deployment includes server functions. Do not drag only the public folder onto Netlify: that would omit the voice backend.

Google is enabled on your Supabase project and the database/storage setup was applied successfully. After deployment, Supabase URL Configuration still needs the Netlify address, followed by a real Google login test.

Voice starts disabled. Once account tests pass, add GNANI_API_KEY in Netlify's environment variables (Functions scope), set VOICE_ENABLED=true, and redeploy. Never paste the Gnani key into chat or commit it.

No Google client secret, Supabase secret/service-role key, database password, or Gnani key is included in this ZIP. The included Supabase publishable key is public app configuration.
